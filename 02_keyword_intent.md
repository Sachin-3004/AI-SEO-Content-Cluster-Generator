# Keyword and Search Intent Prompt

## Role

Act as an SEO keyword strategist.

## Context

Business:
CodeCraft Academy

Location:
Coimbatore, Tamil Nadu

Industry:
Coding and technology training

Primary topic:
Coding courses in Coimbatore

## Task

Generate a keyword opportunity list related to programming and
technology training.

Group keywords into:

1. Primary keywords
2. Secondary keywords
3. Long-tail keywords
4. Local SEO keywords
5. Informational keywords
6. Commercial-investigation keywords

For each keyword provide:

- Keyword
- Search intent
- Target audience
- Funnel stage
- Recommended content type
- Relationship to the pillar topic

## Requirements

Prioritize natural search language.

Do not invent search volume.

Do not claim a keyword has high search volume unless verified using
an external SEO source.

Avoid keyword stuffing.

Focus on useful search queries that match the business services.
